# Engineering Computer Applications - MATLAB Projects

This repository contains a curated set of MATLAB projects completed for engineering computation coursework.

It includes:

- A final project, `FinalProject_Pizza`, presented at the UHART Expo on May 6, 2026.
- A 10-project assignment collection (`Mod1Project*` and `Mod2Project*`).
- An `EnergyDashboard` project that uses two MATLAB files plus a CSV dataset.

## Repository Purpose

The goal of this repository is to document progress across multiple MATLAB assignments and demonstrate practical engineering computation skills, including:

- Problem formulation and algorithmic thinking.
- MATLAB scripting, data handling, and visualization.
- Incremental project development from module exercises to a final showcase project.
